# Kirols Manasa — Portfolio

Personal portfolio website with a cinematic, animation-first experience.

**Live:** https://kirols-portfolio.vercel.app

## Highlights

- Intro screen with a staggered image reveal and counter
- Mouse-reactive image reveal in the hero (desktop)
- Smooth scrolling and animated section transitions
- Pinned projects section that wipes between work as you scroll
- Responsive layout and SEO metadata (Open Graph, Twitter cards)

## Tech Stack

Next.js 15 · React 19 · TypeScript · Tailwind CSS · GSAP · Lenis

> Frontend only. The project was scaffolded with create-t3-app, but no backend features are used.

## Run locally

```bash

cd portfolio
npm install
npm run dev
```

Open http://localhost:3000.
